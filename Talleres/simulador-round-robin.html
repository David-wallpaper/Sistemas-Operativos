01 · Entradas

Editables

TA = tiempo de llegada. CPU = ráfaga total requerida. Todos los tiempos se expresan en unidades (u.t.).

ProcesoTACPUQuitar

Simulación preparada con quantum 3. Cada paso avanza un turno o un intervalo inactivo.

Reglas del modelo
  • Una CPU, una ráfaga por proceso, sin E/S ni costo de cambio de contexto.
  • Cola FIFO: cada proceso ejecuta como máximo un quantum. Si le falta CPU, vuelve al final.
  • Las llegadas durante un turno no interrumpen al proceso. Se agregan a la cola por orden de llegada.
  • Si una llegada coincide con el final del quantum, se encola antes de reinsertar al proceso saliente.
  • Si varios procesos llegan juntos, se respeta el orden de las filas.
  • Si no hay procesos listos, la CPU queda inactiva hasta la siguiente llegada.
  • Límites: 1–20 procesos; TA de 0 a 10 000; CPU y quantum de 1 a 1 000; suma de CPU hasta 2 000. Solo enteros.

Listo para entregar

El archivo funciona sin conexión. La descarga conserva tu nombre, las entradas y el quantum.

Guion · menos de 3 minutos
  1. 0:00–0:30. “Este simulador representa Round Robin. Cada proceso recibe un turno de CPU limitado por el quantum. Si no termina, regresa al final de la cola”.
  2. 0:30–1:10. Muestra el ejemplo: P1 (TA 0, CPU 5), P2 (TA 1, CPU 3), P3 (TA 2, CPU 1), quantum 2. Pulsa Siguiente turno. “P1 ejecuta de 0 a 2; quedan tres unidades. P2 y P3 esperan delante de P1”.
  3. 1:10–2:10. Ingresa una entrada nueva: P4, TA 3, CPU 2. Cambia el quantum a 3, pulsa Preparar simulación y Reproducir. Explica que los turnos duran hasta tres unidades.
  4. 2:10–2:45. Pulsa Ver resultado. “El diagrama muestra los turnos. El retorno es finalización menos llegada; la espera es retorno menos CPU; la respuesta es primera ejecución menos llegada”.
